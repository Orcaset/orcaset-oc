# Tootsie Roll Industries

This example builds a financial projection model for Tootsie Roll Industries (TR). It includes income, cash flow, and balance sheet statements.

This example was created entirely by an agent in a single shot with instructions to make up "reasonable assumptions". It highlights how agents can safely and efficiently use orcaset to build trustworthy financial models, pending of course actual guidance or context on deriving more accurate assumptions.

> Data integration: Historical data through Q4 2025 is loaded from flat CSV files. Data sourcing could be redirected to a database or over the web with minimal code changes.

## Output

Executing this example requires passing the paths for the historical income, balance sheet, and cash flow CSV files in that order.

```sh
dune build && dune exec examples/5-Tootsie-Roll/main.exe -- examples/5-Tootsie-Roll/historical-is.csv examples/5-Tootsie-Roll/historical-bs.csv examples/5-Tootsie-Roll/historical-cf.csv 
```
