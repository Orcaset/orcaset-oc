# Install `orcaset-ocaml` skill

Install the `orcaset-ocaml` skill by pasting the command below into your coding agent.

```txt
Install the skill from https://github.com/Orcaset/orcaset-oc/tree/main/skill/orcaset-ocaml
```

Alternatively, download this repo and copy the skill files manually into your agent's skills directory.
